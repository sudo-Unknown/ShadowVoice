Connect a Real Phone Number via Twilio

Follow these 3 simple steps to have your AI answer real incoming calls from any mobile phone.

1

Expose Server with Cloudflare Tunnel

Run the tunnel script in terminal to get an instant public HTTPS address for this machine:

npm run tunnel

This uses the installed cloudflared binary to route incoming traffic securely.

2

Configure Twilio Phone Number

Open your Twilio Console > Phone Numbers > Active Numbers:

  • Scroll down to the Voice Configuration section.
  • Under "A Call Comes In", select Webhook.
  • Paste your webhook URL:
    https://<your-tunnel-subdomain>/api/twilio/voice
  • Set HTTP Method to HTTP POST and click Save.
3

Call Your Number & Talk!

Dial your Twilio phone number from any phone. The AI representative will answer, greet you warmly, converse in natural spoken voice, take your message, and immediately post the parsed voicemail to this inbox!
